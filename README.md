# Podkop (Xray edition) — установка

Готовые пакеты Podkop на ядре Xray-core для OpenWrt 24.10+ (opkg) и 25.12+ (apk).
Исходный код в этом репозитории не публикуется — здесь только установщик и релизы.

## Установка одной командой

Выполните на роутере по SSH:

```sh
sh <(wget -O - https://raw.githubusercontent.com/Shytyan/podkop-xray-dist/main/install.sh)
```

Установщик:
- удалит старый podkop (в том числе оригинальный на sing-box) и его настройки — копия конфига сохранится в `/etc/config/podkop.bak-<дата>`;
- поставит зависимости и пакеты `podkop`, `luci-app-podkop` из последнего релиза;
- спросит, ставить ли русский язык интерфейса (`luci-i18n-podkop-ru`), иначе останется английский;
- поставит самую новую версию Xray-core;
- поставит `https-dns-proxy` в безопасной конфигурации (его сервис выключен, dnsmasq и порт 53 не трогает — его запускает podkop): все DNS-запросы уходят только на ваш DoH-сервер, тест утечек показывает только его.

Параметры: `-y` — без вопросов (язык английский), `--ru` — сразу с русским языком,
`--xray-prerelease` — Xray-core вместе с pre-release, `--no-doh-proxy` — без `https-dns-proxy`.

После установки откройте LuCI → Services → Podkop, добавьте ссылку на сервер и нажмите «Сохранить и применить».

## Что нового в 0.20261021

- Списки, в которых есть и домены, и подсети, снова работают без full route: раньше трафик таких списков уходил напрямую.
- Ошибки `failed to resolve ip > features/dns: empty response` исправлены.
- Проверка FakeIP в браузере работает и показывает честный результат.
- DNS без утечек: запросы любых типов идут на ваш основной DNS (DoH), российские домены — на региональный DNS.
- «Сохранить и применить» больше не оставляет сеть без прокси на 15–30 с: новая конфигурация собирается, пока работает текущая; некорректная конфигурация не применяется.
- Старые ошибки в LuCI больше не всплывают при каждом открытии страницы.
